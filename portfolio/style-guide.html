Back to top (.totop)

Fixed bottom-right circle, added to every page after the footer. The ring text rotates with scroll (1° per 5px), fades in after half a viewport, and scrolls to the top through Lenis on click. It is live on this page: scroll down to see it.

<!-- Back to top: fixed circle, "TOP" on the ring, rotates with scroll -->
<a href="#" class="totop" aria-label="Back to top" data-totop>
  <svg class="totop_arrow" viewBox="0 0 24 24" width="22" height="22" fill="none" aria-hidden="true"><path d="M12 19V5M5.5 11.5L12 5l6.5 6.5" stroke="currentColor" stroke-width="1.4" stroke-linecap="square"/></svg>
</a>
<script>
(function(){
  var el=document.querySelector('[data-totop]'); if(!el) return;
  var ring=el.querySelector('.totop_ring'); var ticking=false;
  function update(){
    var y=window.scrollY||document.documentElement.scrollTop||0;
    if(ring)ring.style.transform='rotate('+(y/5)+'deg)';
    el.classList.toggle('is-visible', y>window.innerHeight*1.5);
    ticking=false;
  }
  window.addEventListener('scroll',function(){ if(!ticking){ requestAnimationFrame(update); ticking=true; } },{passive:true});
  update();
  el.addEventListener('click',function(e){
    e.preventDefault();
    if(typeof lenis!=='undefined' && lenis && lenis.scrollTo){ lenis.scrollTo(0,{duration:1.4}); }
    else { window.scrollTo({top:0,behavior:'smooth'}); }
  });
})();
</script>

Behaviors & attributes

What the inline scripts and data attributes do, so you can reuse them on new pages.

data-gsap="parallax-section" + data-gsap="parallax-img"

GSAP ScrollTrigger parallax. The image is 110% tall and scrubs with scroll. Elements are hidden until JS runs (see the inline style in <head>).

data-css="clip-hero" / "clip-bg" / "clip-top"

CSS mask-image with the torn-paper SVGs in assets/ (hero-clip.svg, quote-top-clip.svg, clip-top.svg).

data-wf--button--variant="base|secondary"

Webflow component variant marker. The secondary look comes from the .w-variant-29a1217e-… class; keep both in sync.

.footer-time

Filled every minute with the current Los Angeles time by the inline script at the end of each page.

.copyright-year

Replaced with the current year on load.

.footer_bg.cc-left / .cc-right

Blurred progressively while the footer scrolls into view (GSAP timeline, scrub).

Lenis

Smooth scrolling (assets/vendor/lenis…). Synced to GSAP ticker. Add data-lenis-prevent to any scroll container you want native.

SplitText, DrawSVGPlugin

Loaded for text reveals and SVG line draws (about and contact graphics, footer sun).

.w-mod-js / .w-mod-ix3

Webflow runtime flags on <html>. The head style hides animated elements until .w-mod-js is present.

Page-specific Webflow JS

Each page loads webflow.schunk… plus one page bundle (webflow.b62583b6… home, webflow.13f90722… about/projects/courses/project pages, webflow.4f006618… contact and 401, webflow.54676833… 404). Copy the matching pair when you duplicate a page.
